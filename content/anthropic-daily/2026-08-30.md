# The Wrapper Reckoning

Sunday, August 30, 2026. Two products moved in the same 24-hour window. One was erased; one was born. Both are wrapper-economy plays. The DALL-E GPT is gone. Grok Bot templates arrived. Anthropic reset the Claude Code limits clock.

## Lead: The Wrapper Reckoning

OpenAI retired the DALL-E GPT from ChatGPT on August 30. Not retired with a transition period. Removed. Users who navigate to it now see a prompt to switch to ChatGPT Images, running on gpt-image-1 and gpt-image-1-mini. Images stored in its conversation history were available for download through the cutoff. After that: gone.

The mechanism is worth naming precisely. This was not the deprecation of DALL-E as a model. It was the retirement of the DALL-E GPT, the first-party OpenAI-authored GPT that appeared pre-installed in every ChatGPT account when the GPT Store launched in January 2024. Third-party GPTs with image generation still work. What died is the flagship first-party use case: the proof-of-concept for why GPTs existed.

The blast radius reaches everyone who linked to it in a tutorial, built a workflow that started from it, or used it as the exemplar in a pitch deck about the GPT Store. Also anyone whose mental model of what GPTs are for was anchored to that use case. Which is a lot of people, because that use case was the headline. Less visible: the downstream effect on third-party tutorials and YouTube walkthroughs that have accumulated since 2024. Those now route to a dead endpoint. Every "how to generate images in ChatGPT for free" video is now a misdirection.

The GPT Store launched with enormous fanfare. OpenAI projected it would give ordinary users a way to build and distribute AI software without writing a line of code. Two years later, the use cases that worked became features, and the use cases that did not stacked up as abandoned wrappers. The Store is still live. The flagship first-party GPTs that anchored it are disappearing one by one into the native product, which is a more honest description of what GPT-as-feature-prototype always meant.

The pattern is more interesting than the single event. Across 2026, OpenAI has absorbed GPTs-as-wrappers back into first-party features, one at a time. Memory went native. Deep Research went native. Image generation went native. Each time, the wrapper that existed because the underlying product could not yet do the thing got replaced by the product doing the thing. The wrapper tier is a staging area: the place features go before they are real, not the place you build a business.

There is a second-order implication for anyone who built a third-party GPT with a distribution strategy that depended on discoverability from first-party GPT neighbors. When the first-party anchors disappear from the default chat interface, the Store loses the foot traffic those anchors generated. Third-party GPTs that sat near the DALL-E GPT in recommended-apps placements are the collateral. The Store's health as a discovery channel has always been correlated with whether OpenAI itself uses GPTs as the answer to user intent. Increasingly, it does not.

The read: a GPT that existed because ChatGPT could not generate images is now a dead end because ChatGPT can. The GPT Store was a staging area for capabilities, not a platform for products. OpenAI is clearing it of completed migrations. The ones that survive are wrappers that add something the native product still cannot do. That set is shrinking with each model generation.

## Also Shipped: The Code Limits Reset

Via @ClaudeDevs on August 29, Anthropic confirmed the new steady-state for Claude Code weekly limits. The temporary 50% above-baseline boost, running since Q2, ends September 14. The replacement: a permanent 25% above the original baseline. Net change from current levels: about 17% fewer tokens per week.

The mechanism is a weekly rolling ceiling at the plan level. Pro, Max, Team, and Enterprise seat plans all receive the same 25% permanent uplift. The cadence (weekly, not daily) does not change; the ceiling does. The weekly cadence matters here: a daily limit would let you burn heavy one day and coast the next. The weekly ceiling means a single large session can consume a material fraction of the week's allocation in one sitting, with no reset until the following week's window opens.

The blast radius is precisely the builders who calibrated into the temporary high. A 17% reduction from today's ceiling is enough to push a large refactor from one session to two. The users most exposed are Pro and Max accounts running close to the weekly cap regularly. Not because they are careless, but because they built workflows around what was available. The promotional window lasted long enough that it became the baseline in practice, if not in policy.

The pattern: Anthropic introduced the temporary boost in Q2 to coincide with the Claude Code Windows launch, where new users needed more runway to evaluate. Boosted limits lower the activation cost of the product; standard limits are what the product actually costs to run. The promotional window is over; the product is at steady state. A 25% permanent uplift is still a meaningful improvement over the original launch allocation. The removal of the temporary boost is not a punishment. It is a stabilization.

The contrast: OpenAI's Codex CLI shipped v0.151.0 this weekend with a configurable grace period for MCP server tool discovery, a fix that makes Codex more tolerant of slow-starting MCP servers. Anthropic is adjusting limits; OpenAI is reducing friction in a completely different part of the experience. Both moves read as developer-experience refinements. The vectors are just orthogonal.

The builder's move: check your Claude Code usage before September 14. If you regularly hit the weekly ceiling under the current promotional limits, plan your heaviest sessions in the next two weeks. After the cutover, the same session at the same time of week will consume a larger fraction of your allocation.
