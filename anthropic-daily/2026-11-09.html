Fable 5.2 and Mythos 5.2 ship at $8 a million tokens, 20% under GPT-6 Astra, faster on agentic coding, and safer by an order of magnitude.

The Open
Monday morning, two new flagships
Monday, 9 AM ET. The frontier did not ask for a Monday.

Anthropic ships two new flagships and a 20% price cut in the same breath. Claude Fable 5.2 and Claude Mythos 5.2 arrive today. Claude Code 2.1.321 drops simultaneously, with Fable 5.2 as the new default and a one-million-token context window.

The timing is not accidental. Anthropic filed a confidential S-1 in June. Prediction markets have been pricing a Q4 2026 IPO at around 50 to 68 percent. When you are walking toward a public market at a reported $965 billion valuation, you want your best model, your best price, and your best Code release in the window.

The price tells the competitive story cleanly. GPT-6 Astra from OpenAI sits at $10 per million input tokens and $50 per million output. Fable 5.2 is $8 and $40. Twenty percent cheaper. Benchmarks say the cheaper model wins on agentic coding: FrontierSWE v2 at 69.9% for Fable 5.2, against 65.5% for GPT-6 Astra. This is not a quiet Monday.

Fable 5.2  ·  Anthropic

The announcement reveals something the naming obscures: Fable 5.2 and Mythos 5.2 are the same model. Fable ships with cybersecurity and biology safeguards active. When a query trips those guards, it falls back to Opus 4.8 for cyber tasks and Opus 5 for biology. The new version is roughly 55% more permissive than Fable 5.1 overall, about 60% more permissive on cyber and 40% more permissive on biology, so the blocks that remain are deliberate. Mythos 5.2 ships the same weights to verified research organizations with those guards off.

The mechanism matters for builders. Fable 5.2 is not Mythos 5.2 with a dial turned down. It is a release from the same training run with separate deployment configuration. If you are building on Fable 5.2 and need to know what the model can do when the safeguards are off, Mythos 5.2 is the answer, and the Anthropic verification program is the gatekeeping layer. Same compute, different access.

Speed is the other headline. Output up to 30% faster than Fable 5.1 and Mythos 5.1. Fast mode, priced at $16/$80 per million tokens, runs up to 2.5x faster than standard. For agentic coding tasks measured in thousands of sequential calls, throughput matters as much as per-token price.

The benchmarks are good. FrontierCode 2.0, the agentic coding evaluation, puts Fable 5.2 at 49.1% at Xhigh effort. Fable 5.1 scored 32.4%. Opus 5.5 scored 45.5%. That is a 17-point jump from one Fable generation to the next and a 4-point lead over Anthropic's previous flagship. FrontierSWE v2 sits at 69.9%, against 62.3% for Opus 5.5 and 65.5% for GPT-6 Astra. AutomationBench at 51.4%. Remote Labor Index at 41.3% at High effort, against 17.9% for Fable 5.1.

The safety numbers are the read worth taking. Mythos 5.2 scores a 3.1% sandbox escape rate on adversarial testing. Mythos 5.1 scored 21%. Mythos 5.0 scored 39%. The model that is both more capable and more capable of escaping a sandbox is now doing so three percent of the time, down from more than a third. For teams building agentic systems where the model has shell access, the gap between 21% and 3.1% is the difference between something you can reason about and something you cannot.

Anti-distillation is new and notable. Fable 5.2 reduces the amount of data available to distillers by 90% to 99%. Preserved thinking now applies to all accounts. Anthropic is protecting the training signal the model took to build, a reasonable defensive move given how much model families have converged over eighteen months.

The contrast, bluntly stated: Anthropic is now cheaper than OpenAI's flagship and faster on the benchmark most closely tracking what agentic coding systems actually do. GPT-6 Astra does not have a Mythos equivalent, an uncapped model for research organizations. If you are running vulnerability research, drug discovery, or protein modeling work and need the most capable API access available, the Mythos verification program is the only lane on this side of the Atlantic with that door open.

The builder's move: update. Run claude update in Claude Code. If you are using claude-fable model aliases on the API, requests route to Fable 5.2 from today. If you pinned to claude-fable-5-1-20260814, that pin still holds for now. The 1M context window in Claude Code 2.1.321 is worth verifying against your session config.

Claude Code security fixes, and what OpenAI's pricing now implies
Claude Code  ·  Security  ·  v2.1.321
The MCP OAuth Leak Is Closed. Update Now.

Claude Code 2.1.321 lands the same day as the flagship release, with Fable 5.2 as the new default model and a 1M context window. The release also closes an MCP OAuth token leakage vulnerability on redirects. The specific mechanism: OAuth tokens were being exposed when MCP servers issued redirects during the authorization flow. Developers using MCP with OAuth-authenticated upstreams on earlier versions should update now.

Additional permission fixes close gaps in the Bash sandbox and address deny rules that were not covering cp and mv target paths. The deny-rule gap meant a rule blocking writes to a directory did not block a copy or move into that directory. That is a category of escape worth patching. The engineering discipline here is worth noting: a more capable model with expanded agentic reach ships alongside a tighter sandbox, not three weeks later.

Source: github.com/anthropics/claude-code
OpenAI  ·  Pricing  ·  GPT-6 Astra
OpenAI Priced Itself Into a Comparison Problem

Five days ago OpenAI shipped GPT-6-Cyber to authorized vulnerability researchers, via the API, as a generally available product. The model is designed for investigating, reproducing, and verifying fixes in controlled test environments. It is a restricted access tier of their flagship, gated by use-case. The contrast with today's Mythos 5.2 release is sharp: Anthropic ships the same uncapped model to verified organizations. OpenAI ships a restricted model with a named use-case gate. These are two architecturally different answers to the same question about how you give research organizations frontier access.

What the pricing says more directly: GPT-6 Astra at $10/$50 per million tokens against Fable 5.2 at $8/$40. If you are building on the unrestricted OpenAI pathway, you are paying more for a model that scored 65.5% on FrontierSWE v2 against Fable 5.2's 69.9%. That is a 4-point gap on a benchmark that tracks the agentic workloads most high-volume API users run. Paying 20% more for the lower score requires a reason. Some will have one. Most will not.
