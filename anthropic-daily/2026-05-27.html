Lead

v2.1.152 landed at 01:30 UTC and makes three changes worth tracking. /code-review --fix now applies review findings to the working tree directly after the review runs. /simplify becomes an alias for it. That is a workflow compression. The second change: a new MessageDisplay hook event lets teams intercept and transform assistant message text before it renders. The third: Auto mode drops its opt-in consent requirement. The friction gate is gone by default. github.com/anthropics/claude-code/releases

v2.1.153 followed at 00:52 UTC on the 28th, still inside the window. Status line commands now receive COLUMNS and LINES environment variables for terminal-aware output sizing. macOS background agents surface in Privacy and Security as "Claude Code" with persistent permissions. claude agents autocomplete picks up native slash commands and bundled skills. /model saves the selection as the default unless you press s to scope it to the current session only.
