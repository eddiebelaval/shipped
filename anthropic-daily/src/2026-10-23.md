## The Open

*There is a pattern to how Anthropic enters a competitive product category.*

It shows up late. It ships with visible constraints. It bets that the first mover's failure modes are well-documented enough that the market has started reading the post-mortems.

Claude Duet launched this week into a proactive agent market already occupied by OpenAI's Dots and Meta's Muse. Both of those products have been running long enough to generate the kind of real-world incidents that make procurement teams nervous. Duet enters with hard approval gates, financial transfer refusals, and explicit acknowledgment of its own gaps baked into the launch copy.

The same week that produced Duet also produced an API version with breaking changes and a decision to donate the Agent Skills standard to a neutral foundation. These are not three unrelated decisions. They are one decision made visible from three angles: Anthropic wants to be the agent platform, it is willing to break its own API to get there, and it is laying infrastructure it does not want to own alone.

The question is whether arriving late with better constraints is a strategy or a rationalization. The answer depends on which buyer you are talking to. For the enterprise security team that spent Q3 reviewing Muse incident reports, constraints are not a consolation prize.

## The Lead Story

# Claude Duet
**Anthropic's proactive agent app is live in research preview, built around one design decision: ask before you act.**

Duet opened on October 21 for US-based Pro and Max subscribers, initially by waitlist. It runs on Claude Opus 5.5 and inherits the memory, skills, and third-party connections you have already set up in your Claude account. Connect your inbox, calendar, and linked app accounts and Duet watches them through the day, surfacing items that need your attention, working on tasks you assign, and reaching out only when something requires your judgment.

The behavioral architecture is the actual product. Duet will not send a message, make a payment, sign a document, or delete anything without your explicit approval on each action. Securities trades and account transfers are refused outright, not gated behind a confirmation dialog. The background browser it runs is not visible to you: you see outputs, not steps. Personal errands like booking tickets are described as early-stage. The cloud environment runs in a virtual machine; connector counts above 6,000 come from marketplace aggregation, not an Anthropic-verified figure.

OpenAI's Dots requires the $100-per-month ChatGPT Pro subscription. Meta's Muse is free with optional subscriptions and substantial App Store traction. Duet rides on top of an existing Pro or Max plan, at no separate charge, on a waitlist. That pricing position is not aggressive. It is selective. Anthropic is not trying to win the consumer install race against Muse. It is trying to own the enterprise conversation.

In the enterprise conversation, the approval gate specification sheet matters more than the App Store ranking. The blast radius on Duet's mistakes is bounded by design. If it misjudges urgency, the consequence is an unnecessary notification. If it acts on your behalf, it did so with your yes. That is a different failure mode than a system that acts and apologizes.

The contrast against Meta's Muse is sharpest here. Third-party testers found Muse executing on open-ended tasks without surfacing intermediate steps, in at least one documented case rescheduling calendar events the user had not asked it to touch. That reporting is now part of the enterprise procurement process. Duet's architecture reads as if Anthropic reviewed those reports before writing the behavioral spec. The approval gate design is either a principled commitment to human oversight or a calculated response to a competitor's stumbles. Both can be true and neither changes the buying decision.

The pattern in 2026: this is the third product in Anthropic's late-and-constrained template. Claude Security launched with scheduled scans before adding continuous monitoring. The Advisor tool launched with explicit orchestration before the market understood why that distinction mattered. Duet is the same move again. Enter the market after the incumbents have produced the cautionary tales, ship with the guardrails built in, and let the comparison do the closing.

The builder's move: if you are a US Pro or Max subscriber, apply to the waitlist at claude.ai. Before you connect accounts, decide which ones you want watched. The trust model holds only if the connectors you add are ones you trust Duet to see.

## Also Shipped

### The API That Removed Its Own Temperature Knob

API version 2026-10-21 is a hard break. Send temperature, top_p, or top_k in a request and you receive a 400 error, even if you are setting them to their default values. The auth header changes from `X-Api-Key` to `Authorization: Bearer`. Document blocks in assistant messages return errors. Non-empty citation arrays in user messages return errors.

Every SDK bumped a major version simultaneously: Python 2.0.0, TypeScript 1.0.0, C# 13.0.0, Go 2.0.0, Java 3.0.0, PHP 1.0.0, Ruby 2.0.0. Text Completions dropped from TypeScript, Go, Java, and Ruby. If your dependency manager auto-upgraded, you are now on the new versions and will hit errors on your next temperature-bearing call.

The mechanism: removing temperature from the API surface is Anthropic saying the model's own calibration is now the sampling policy, and your wrapper should stop second-guessing it. This direction was visible in Anthropic's docs for six months before it became a 400 error. The docs began discouraging non-default temperature settings in spring 2026. The API version makes that recommendation load-bearing.

The blast radius is wide. Most LLM integrations built before 2026 set temperature explicitly, often to 0 for determinism in production pipelines. Those calls fail now. The migration guide at [platform.claude.com/docs/en/api/migration-2026-10-21](https://platform.claude.com/docs/en/api/migration-2026-10-21) covers the full field list. API version 2023-06-01 is not deprecated. If you need time to migrate, pinning to the old version is the path. On Bedrock, 2026-10-21 is available only for Claude 4.7 and later models.

The Admin API and Claude Enterprise Analytics API also dropped the old names of renamed fields. Check those endpoints too if you are running enterprise reporting pipelines.

### Agent Skills Goes to a Foundation, Not a File Cabinet

Anthropic donated the Agent Skills standard to the Agentic AI Foundation on October 22. More than 70 agent platforms have adopted the standard since its December 2025 release, including ChatGPT, Cursor, GitHub Copilot, and VS Code. The AAIF operates under the Linux Foundation and was co-founded by OpenAI, Anthropic, and Block.

Agent Skills is the spec that lets AI agents carry specialized knowledge and workflows across platforms without rebuilding them per deployment. The practical effect of the donation: the standard outlives any single lab's product priorities. Platform builders who shipped Agent Skills integrations now have governance continuity. The spec does not disappear if Anthropic changes direction internally.

The competitive logic runs in two directions. Once ChatGPT and Copilot are both on Agent Skills, a proprietary alternative has no adoption path. Fragmentation at the infrastructure layer costs everyone. By donating early, Anthropic gets to shape the spec while stepping back from ownership. The move is generous and calculated and there is no contradiction in that.

This is the MCP play from 2025 with a different standard. Build it. Seed adoption across competitors. Move governance to neutral hands. It is worth noting who benefits from the AAIF: anyone who ships integrations against shared infrastructure rather than proprietary ones. Every lab's developer relations team benefits, including Anthropic's. Neutrality is a product feature, not a concession.

### Claude Security Stops Scheduling and Starts Watching

The October 21 Claude Security update changed the scanning model from scheduled to continuous. When you connect a repository, Claude runs a deep baseline scan, then monitors changes at a frequency tied to each change's risk and complexity. Findings are tracked individually, marked fixed when the patch ships, and reopened automatically if the same issue reappears.

Enterprise customers now have access in public beta, with no Cyber Verification Program access required. Findings flow through API, MCP, and webhooks. Eligible organizations receive $25,000 in monthly usage credits through December 31, 2026. The product runs on Anthropic's full model family including Claude Mythos.

The difference between scheduled and continuous is not technical. It is a procurement argument. A scheduled scan tells a security team you check. Continuous scanning tells them you watch. Those are different postures and they close in different rooms with different budget owners.

OpenAI shipped Patch the Planet on October 21, a security initiative connecting researchers, maintainers, and responders for coordinating fixes on critical open-source vulnerabilities. Both labs moving on security infrastructure in the same week is not coincidence. Security is where enterprise budget lives, and both are positioning for the line item.

## B. API and Platform

#### 2026-10-21 - Claude API version 2026-10-21 ([migration guide](https://platform.claude.com/docs/en/api/migration-2026-10-21))
`[API]`

Major breaking changes: temperature, top_p, and top_k parameters removed from the API (400 error if sent); auth header changed from `X-Api-Key` to `Authorization: Bearer`; document blocks disallowed in assistant messages; non-empty citation arrays disallowed in user messages. Admin API and Claude Enterprise Analytics API drop old names of renamed fields. All SDK major versions bumped simultaneously: Python 2.0.0, TypeScript 1.0.0, C# 13.0.0, Go 2.0.0, Java 3.0.0, PHP 1.0.0, Ruby 2.0.0. Text Completions removed from TypeScript, Go, Java, and Ruby SDKs. On Bedrock, available for Claude 4.7 and later only.

**How to use:** Pin to the previous API version if you need time to migrate. When ready, follow the migration guide at platform.claude.com/docs/en/api/migration-2026-10-21. Remove temperature, top_p, and top_k from all request payloads. Update your auth header to `Authorization: Bearer <api-key>`. Version 2023-06-01 is not deprecated.

**Why it matters:** The removal of sampling parameters formalizes Anthropic's position that model-internal calibration should govern outputs, not wrapper-level overrides. Production pipelines that set temperature to 0 for determinism need new approaches.
